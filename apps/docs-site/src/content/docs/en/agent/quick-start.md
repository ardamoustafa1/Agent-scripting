---
title: "Agent quick guide"
---

1. Sign in through SSO and check campaign permission/connection status.
2. Accept the secure launch offer for the incoming call/chat. The correct screen is selected automatically.
3. Read and acknowledge required text, complete fields and choose Next. On read-only/offline warnings,
   wait for reconnection rather than resending commands.
4. Select the outcome, add a required note and complete wrap-up. Report failed write-back to a supervisor;
   do not retry the same operation from another window.

![Schematic secure interaction to wrap-up](/guides/agent-en.svg)

| Shortcut | Behavior |
| --- | --- |
| Ctrl + / | Help/shortcut panel |
| Alt + Left | Previous page |
| Enter | Next when active/online and focus context permits |
| Tab / Shift + Tab | Forward/backward focus |

Enter does not intercept textarea, dialog, combobox or focused buttons/links. Validation/mustRead
may block progress. Adding customer/script/campaign IDs to a URL provides no launch permission.
Never use another agent’s session link. Real screenshot capture acceptance remains pending.
