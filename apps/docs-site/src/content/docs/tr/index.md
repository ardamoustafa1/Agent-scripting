Verbis ile kampanyaya uygun agent ekranlarını tasarlayın, güvenli başlatın ve sonuçlarını izleyin.

- [İlk scriptim](/tr/designer/first-script/): sıfırdan başlayın.
- [Agent kısa rehberi](/tr/agent/quick-start/): çağrı, ekran, wrap-up.
- [SSO kurulumu](/tr/admin/sso/): kurum kimliğini bağlayın.
- [Connector kurulumu](/tr/connectors/setup/): vendor bağlantısını hazırlayın.
- [REST API](/tr/developer/rest-api/): repodaki OpenAPI sözleşmesi.
- [Demo hazırlığı](/tr/demo/): dört Türkçe kampanya ve üç dakikalık sunum.

Bu rehberler mevcut ürün davranışına dayanır. Vendor sandbox kabulü, gerçek ekran görüntüleri ve test sonuçları ayrıca doğrulanmalıdır.
