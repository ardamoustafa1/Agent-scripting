# ASVS 4.0 L2 / kritik alanlarda L3 kontrol envanteri

Sürüm **4.0.3** sabitlenmiştir; resmi kaynaktaki tüm madde kimlikleri aşağıdadır.
[Resmi gereksinim metinleri](https://github.com/OWASP/ASVS/tree/v4.0.3/4.0/docs_en)
ve makine okunur [pinli manifest](asvs-manifest.json) kaynak SHA-256'sını, seviyeleri,
kanıt türünü ve açık doğrulama işini saklar. Test/tarama çalıştırılmadı; **PASS veya
ASVS uyum sertifikası yoktur**. Bölüm referansı bireysel maddenin karşılandığını kanıtlamaz.

Durumlar:

- `KOD_KANITI_TEST_BEKLIYOR`: somut kontrol kodu ve yazılmış test/politika var; yürütme ve madde kapsamının tamamı için doğrulama gerekir.
- `MADDE_DENETIMI_BEKLIYOR`: yalnızca aday modül referansı var; maddeye özgü denetim/kanıt henüz tamamlanmadı. Açık release gate'tir.
- `UYGULAMA_ACIGI`: tespit edilen açık uygulama gereksinimi; uyumluluk iddiasını engeller.
- `SECILEN_KAPSAM_DISI`: L2 ve seçilen kritik L3 hedefinde zorunlu değil; evrensel N/A veya uygulanamaz iddiası değildir.

Kritik L3 alanları: mimari, authentication, session, access control, cryptography,
veri koruma, iletişim ve API/websocket. Diğer bölümler L2. Gerçek deployment'ta
feature kapsamına göre dış değerlendirici tüm uygulanabilir L3 maddelerini artırabilir.

Toplam 286 madde: MADDE_DENETIMI_BEKLIYOR=240, SECILEN_KAPSAM_DISI=14, KOD_KANITI_TEST_BEKLIYOR=31, UYGULAMA_ACIGI=1.

Öncelikli kapatılan kod boşlukları: Redis rate limiting fail-open, fazla geniş health
muafiyeti, auth/launch IP limiti, plugin unsafe-inline, production nonce/Trusted Types,
parent DOM'daki raw secure field, imzasız/replay edilebilir PSP receipt sınırı,
plaintext read-model PII default, gitleaks fallback, unfixed vulnerability istisnası,
SBOM/ZAP eksikliği, Node runtime shell/rootfs hardening ve aydınlatma/rıza bileşenleri.

Kalan kritik doğrulamalar: TLS/ingress + tenant frame-ancestors dağıtımı, IdP MFA ve
session politikasının fiili enforcement'ı, KMS/PSP kuruluş kanıtları, eski PII default
verilerinin temizliği, deploy seccomp/read-only politikası, auth API DAST ve bağımsız
pentest. Ayrıca `MADDE_DENETIMI_BEKLIYOR` satırları için tek tek denetim gerekir;
bu belge tam sistem uygunluk denetimi tamamlandı iddiası taşımaz.
